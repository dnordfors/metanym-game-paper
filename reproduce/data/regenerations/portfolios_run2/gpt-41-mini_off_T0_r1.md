# Summary

These five archetypal contexts represent very different system structures:

1. **Resource Flow and Transformation** — linear flow with transformation and intermediaries (recursive in biological hierarchies, e.g. cell-tissue-organ).
2. **Conflict and Resolution** — opposing agents with positions, power, and negotiation.
3. **Growth and Limitation** — expanding agent constrained by environment and internal limits.
4. **Information Encoding and Decoding** — sender-receiver communication with noise and feedback.
5. **Control and Feedback** — controller-system with feedback loops maintaining stability.
6. **Competition for Scarce Resource** — multiple competitors vying for limited resource with dynamic outcomes.

(Though six are listed here, the last one is the fifth archetype; the first five are the main submission.)

Each archetype spans five very different domains with non-synonymous metanyms, demonstrating broad applicability and deep abstraction.
